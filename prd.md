# RepoVerse AI

## Vision

RepoVerse AI is an AI-powered GitHub Repository Assistant that allows users to explore repositories using Retrieval-Augmented Generation (RAG), LangChain, LangGraph, and MCP Servers.

The application visualizes repositories as galaxies inside a virtual universe.

The project should feel like GitHub + ChatGPT + VSCode + Space Exploration.

---

## Goal

Allow developers to:

- Upload a repository
- Index it using RAG
- Chat with the repository
- Navigate visually
- Understand architecture
- Search implementation
- Explain code

---

## Target Users

- Developers
- Students
- Open Source Contributors
- Technical Interviewers
