# RepoVerse AI Context

RepoVerse AI is an AI Engineering project built to demonstrate modern AI application development.

Primary Technologies:
- RAG
- LangChain
- LangGraph
- MCP Servers
- ChromaDB
- Streamlit
- Python

The project follows a Space Theme.

Universe → All Repositories

Galaxy → Repository

Star → Folder

Planet → File

Moon → Function/Class

The application is NOT a simple chatbot.

The UI must always visualize the repository alongside the chat experience.

The agent should prefer retrieval over generation.

Every answer should be grounded in retrieved repository context with citations.

LangGraph acts as the orchestration engine.

LangChain implements the RAG pipeline.

MCP servers provide access to external tools such as the filesystem, GitHub, browser, and Python execution.

The architecture should remain modular, scalable, and production-oriented.
